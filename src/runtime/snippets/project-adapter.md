# CatPaw Project Protocol

- 普通项目 Work 先读 `~/.catpaw/runtime-policy.md`，按触发条件读取细则；
  本入口不复制工作流、协作和 Git 授权规则。
- 用 `Work / Proof / Approval` 与 `Understand -> Execute -> Check -> Finish`
  沟通，在既有授权内持续推进。CatPaw 不能扩大用户、项目或宿主权限。
- 项目 `.catpaw/` 保存 Work、Plan 和 Proof，不是 runtime 副本；Approval 不是看板工件。
  先用 `catpaw status` 恢复进度；旧 `legacy/schema-1/` 仅作历史参考。
